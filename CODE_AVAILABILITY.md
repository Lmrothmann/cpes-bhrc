# Code & Data Availability

## Code availability

All analysis code for this study is openly available in this repository.
Analyses were run in R 4.4.1. The fitted cumulative psychosocial exposome score
(cPES) coefficients (eTable S2) are included, so that the score itself is
reproducible; together with the code, they allow full reproduction of the
analyses by researchers who obtain access to the underlying data.

## Data availability

The data analysed in this study were obtained from the Brazilian High-Risk
Cohort (BHRC) under a data-use agreement. The authors do not own these data
and are not permitted to redistribute them. Requests for data access should be
directed to the cohort investigators / data-access committee (see the BHRC
cohort profile).

Personal file paths in the scripts have been replaced by placeholders
(`<PROJECT_ROOT>`, `${cPES_OUT}`, `<BHRC_INPUT_DIR>`, `<COGNITION_DIR>`); set
them to your local data tree before running.
